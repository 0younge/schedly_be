# Agent Instructions

Before doing any Git-related work in this repository, read:

1. `.codex/git-workflow.md`
2. `.gitmessage.txt` when preparing commits
3. `.github/PULL_REQUEST_TEMPLATE.md` when opening or updating PRs
4. `.github/REVIEW_TEMPLATE.md` when reviewing changes
5. `.github/ISSUE_TEMPLATE/*.md` when creating or updating issues

Git-related work includes branch creation, staging, commit, push, issue creation, PR creation, review, merge, and release-adjacent cleanup.

Follow the workflow files even when the user asks briefly. Keep work units small and make the Git history easy to read.
